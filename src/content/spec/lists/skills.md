# 我常用的 10 个 AI skill（安装方式）

> 配套文章：《作为一个一线开发，我都在用哪些 AI skill》
> 以下 skill 均基于支持 skill 的 AI 编程助手（Claude Code / CodeBuddy 等）。

## 写代码线

1. **project-analysis（代码库分析）** — 我自定义的 skill，逐章出 12 章项目分析报告。
   参考链接：https://github.com/hefy2027/feiyu-skill/tree/main/project-analysis
2. **Grill-me（拷问式对练）** — `/grilling` 围着你追问，把方案磨透。
   参考链接：https://www.skills.sh/mattpocock/skills/grill-me
3. **fireworks-tech-graph（技术图表）** — 架构图 / 数据流 / 时序图，出 SVG+PNG，还能出 GIF。
   参考链接：https://www.skills.sh/yizhiyanhua-ai/fireworks-tech-graph/fireworks-tech-graph
4. **Superpowers 全套（元技能）** — `brainstorming` / `writing-plans` / `subagent-driven-development` / `requesting-code-review` / `systematic-debugging` 等。
   参考链接：https://github.com/obra/superpowers
5. **GitHub（gh CLI 工作流）** — 开 PR、堆叠 PR 合并一句话搞定。
   参考链接：https://www.skills.sh/callstackincubator/agent-skills/github

## 写文章 · 宣传线

6. **humanizer-zh（中文去 AI 味）** — 刮掉宣传腔、谄媚语气，还给五维评分。
   参考链接：https://www.skills.sh/op7418/humanizer-zh/humanizer-zh
7. **imgbb-api（图床上传）** — 一句话把图传 imgbb 拿直链。
   参考链接：https://github.com/KeXu9/imgbb-api
8. **HyperFrames（用 HTML 做视频）** — 把面板做成宣传片 MP4。
   参考链接：https://www.skills.sh/heygen-com/hyperframes/hyperframes
9. **gzh-design（公众号排版）** — Markdown 转可直接粘贴公众号的 HTML。
   参考链接：https://www.skills.sh/isjiamu/gzh-design-skill/gzh-design

## 日常协作

10. **飞书全套（Lark 套件）** — 文档 / IM / 表格 / 多维表格等，随 `lark-cli` 安装自带。
   参考链接：https://open.feishu.cn/document/mcp_open_tools/feishu-cli-let-ai-actually-do-your-work-in-feishu
