## 1. 关系型数据库

### Aiven
- 免费 PostgreSQL / MySQL
- 额度：1 个实例，5GB 存储
- 适合：需要标准 SQL 的项目

### Neon
- Serverless PostgreSQL
- 额度：0.5GB 存储，按需唤醒
- 适合：访问量不稳定的项目，冷启动免费用

### Supabase
- PostgreSQL + 自带 API
- 额度：500MB 数据库，50MB 存储
- 适合：需要一个完整后端的项目

## 2. SQLite（边缘数据库）

### Cloudflare D1
- 与 Workers 天然集成
- 额度：5GB 存储，每天 5 百万次读
- 适合：Cloudflare 生态内的项目

### Turso
- 边缘 SQLite，多地自动同步
- 额度：9GB 存储，每天 1 亿次读
- 适合：需要全球低延迟的应用

## 3. NoSQL

### MongoDB Atlas
- 免费 512MB 存储，共享集群
- 适合：需要文档型数据库的项目

### Upstash
- 免费 Redis（256MB）和 Kafka
- 适合：缓存、消息队列场景

## 4. 怎么选

| 场景 | 推荐 |
|---|---|
| 搭博客、小站，存点配置 | D1 / Neon |
| 需要标准 SQL、多表关联 | Aiven |
| 需要完整后端（Auth + API） | Supabase |
| 需要缓存/消息队列 | Upstash |
| 全球多地域低延迟 | Turso |
