说实话，个人项目选数据库这事，绕了一圈发现根本不用纠结。

市面上号称"免费"的一大堆——Neon、Supabase、PlanetScale（现在已经没免费了，无语）、Turso、MongoDB Atlas……名字听着都挺唬人的。但你真上手就知道有多坑。

Neon 冷启动等三四秒，用户都跑了你数据还没醒。Supabase 七天不访问直接暂停，我过年回老家忘了点一下，回来项目挂了。还有的不绑卡连第二个实例都不让你建。免费是免费，但坑也是真坑。

所以结论很简单——**先 MySQL，再看别的**。现在十个开发者九个用 MySQL，框架默认 MySQL，教程里是 MySQL。没悬念。

试下来就两个能打的：**Aiven** 和 **SQLPub**。

## 一、Aiven —— 不止 MySQL，全家桶都白送

Aiven 是个欧洲的云数据库厂商，免费档覆盖 MySQL、PostgreSQL、Valkey（Redis 的 fork，完全兼容 Redis 命令）、Kafka、OpenSearch。

第一次打开控制台有点意外——本来以为免费平台顶多给你两三个选项，结果服务列表拉了一大串，连 ClickHouse 都有（虽然不在免费档里）。挺唬人的。

![Aiven 服务列表](https://i.ibb.co/t0Mj6XC/aiven-services.png)

说白了，**开一个 MySQL 实例就够 90% 的需求了**。需要缓存再加 Valkey，需要消息队列上 Kafka——每个品类都能免费开一个，各算各的。

### 免费档到底给多少

![Aiven 免费档额度对比](https://i.ibb.co/qYYpQDQ3/aiven-free-tier.png)

图里标的很清楚了，不用绑卡，不是"试用 30 天"那种套路。MySQL 和 PG 各 1G 存储，Valkey 1G 内存，Kafka 250K 吞吐加 5 个 topic，OpenSearch 最夸张——4G 内存 20G 存储，免费档里的头牌，跑个搜索引擎够够的。

另外新注册送 **300 美元额度**，有效期一个月。这一个月的 300 刀够你开什么配置？

![Aiven 300 美元能开什么配置](https://i.ibb.co/Y411jvvL/aiven-credit-quota.png)

到期切回免费档，数据不丢。白嫖体验券，不用白不用。

1GB 存储够不够？我自用 MySQL 挂了四五个小站——博客评论、用户表、埋点数据——加起来不到 1G。别往数据库塞文件就行。

### 怎么开

不用信用卡，邮箱注册，Google 登录也行。

进控制台，点 `Create service`，选 MySQL，Plan 切 Free，Cloud 选 Asia Pacific，起个名，点 Create。

![Aiven 创建 MySQL 实例](https://i.ibb.co/mC6tX6MZ/aiven-create.png)

然后等。两三分钟，我刚开始还以为卡了，刷新了两遍（别学我）。其实后台在分配实例，耐心等就行。

等完了给你完整的连接串——host、port、user、password 全有。

![Aiven MySQL 连接串](https://i.ibb.co/8gm5Dm4B/aiven-connection.png)

往 DBeaver 或 Navicat 一填就连上了，跟你本地的 MySQL 用起来没区别。

Docker 或者云函数用的话，`.env` 里 `DB_HOST`、`DB_PASS` 换成 Aiven 的就跑起来了，零迁移成本。

Valkey、Kafka 一样流程，拿到 host 和密码直接用。

### 几个坑

每个品类限一个免费实例——MySQL、Valkey、Kafka 各一个，不冲突，但同品类不能多开（比如你想开两个 MySQL，不行）。

能选大区但选不了云厂商。你选了 Asia Pacific，到底落 AWS 还是 GCP 随缘。想精细控制得升级。

**没自动备份**，免费嘛，自己 `mysqldump` 定期导。长时间没人访问会休眠，唤醒要几秒。不过只要有人持续用就不会触发。

好了，Aiven 说完了。下面这个是完全不同的路数。

## 二、SQLPub —— 国内 Serverless MySQL

SQLPub 是国内做 Serverless MySQL 的，思路极简：给你一个 MySQL，别的不管。

注册完登录进去，创建数据库、选版本、拿连接串，三分钟。然后用 DBeaver 或 Navicat 连上，建表插数据查数据，跟本地完全一样。

它还自带一个 Web 版 MySQL 工作台，浏览器里写 SQL、看表结构、导数据。不想装客户端直接用网页也行。

### 免费档给多少

**永久免费**，¥0/月。0.5GB 存储，最多 30 个连接，每小时 3.6 万次请求，公网流量 5GB/月。Serverless 架构，没人访问不花钱。

0.5GB 看着少，博客和小工具站够用了。3.6 万次/小时——个人项目一天跑不到这个数。我挂的评论系统跑了快半年，没花过一分钱。

### 怎么开

用邮箱注册，不用手机号。登录控制台，点创建数据库，选 MySQL 8.4（目前最新），几秒钟分配好。

![SQLPub 创建数据库](https://i.ibb.co/7JLSdr3n/sqlpub-create.png)

拿到连接串，往客户端一填，齐活。

![SQLPub 连接信息](https://i.ibb.co/tMtsHT8d/sqlpub-connection.png)

建库建表、增删改查、视图、存储过程——标准 MySQL 该有的都有。

### 几个坑

以前打开网页直接给连接串，现在**要注册了**。不过邮箱就行，不用手机号，也不算麻烦。

Web 工作台是有的。

![SQLPub Web 工作台](https://i.ibb.co/tPLq350q/sqlpub-workbench.png)

重度使用配个本地客户端更顺手。**自己备份**（免费嘛，定期 `mysqldump`），连接串走公网没有 VPC 隔离——个人项目无所谓，敏感数据别放就行。

## 四、够不够用？

有人会说：Aiven 才 1G、SQLPub 才 0.5G，"这也叫推荐？"

但你想你在做什么？一个博客、一个工具站、一个 Side Project。你需要的不是高可用集群，不是读写分离，不是跨地域灾备。**你只需要一个能存数据、写 SQL、不用花钱的数据库。**

这两个给你的是：Aiven 全家桶不用绑卡五分钟连上，SQLPub 纯 MySQL 永久免费零运维。

日活上千了、收入够交 VPS 月费了，再升级。在那之前，免费的就够了。

**别拿来干什么？**

丑话说前头。

**存文件**——头像、视频、附件，放 OSS 或 R2，别塞数据库。1G 分分钟炸。

**跑大报表**——几百行统计 SQL 在免费实例上跑，CPU 吃满，请求排长队。离线分析自己搭个本地库。

**当生产核心**——没备份没高可用，挂了别哭。（别问我怎么知道的。）Side Project 随便造，真金白银的项目老老实实上付费。

定位清楚就不纠结。
