## 先看成品

前阵子发现一个开源项目，叫 **Solara（光域）**。说人话：它把几个音乐搜索接口聚合到一起，部署完就是一个完整的在线音乐播放器。

我花了没几分钟搭好，下面是我部署完之后的界面——

深色背景 + 玻璃拟态，背景色会跟着封面自动变。手机端竖屏也适配好了，通勤路上单手操作没问题。

点一下就开始播。没有弹窗，没有转圈。

## 我花了多久弄出来的

从发现这个项目到部署上线，几分钟。用的是 cfmanager 的一键部署。

对，你没看错——不是半小时，不是一小时。填个名字，点几下确认，等几十秒，链接就出来了。

如果用 Cloudflare Pages 手动部署，稍微多几步（主要是 Fork 仓库、创建 Pages 项目），但也超不过十分钟。

下面跟你讲具体怎么操作，你照着来就行。

## 前期准备

- 一个 **Cloudflare 账号**（去 cloudflare.com 注册，免费）
- 走方式二的话，还需要一个 **GitHub 账号**（拿来 Fork 仓库）

## 方式一：cf-manager 一键部署（推荐）

这一步的核心就是——什么都不用你操心。

打开 cf-manager（获取方式文末说）→ 左侧菜单进 **应用商店** → 搜 **Solara**：

![cfmanager 应用商店，Solara 音乐播放器模板卡片](https://i.ibb.co/sdzqCHwz/cfmanager-store-solara.png)

1. 点 **确认部署**

![一键部署弹窗，填写项目名称、确认部署](https://i.ibb.co/7dTpw48H/cfmanager-deploy-dialog.png)

2. 输入项目名字，比如 `solara-music`
3. 什么都不用管——Pages 项目、API 代理函数自动配好
4. 确认，等几十秒

![cfmanager 一键部署成功，弹出部署地址](https://i.ibb.co/LdcdKfQp/cfmanager-deploy-success.png)

打开链接，你的音乐站就上线了。

一键部署的本质，是帮你跳过了这些步骤：
- 不用翻 GitHub
- 不用在 Cloudflare 后台点来点去
- 不用配环境变量和构建命令
- 不用手动绑 D1 数据库
- 拉的是最新版本，不是几个月前的旧代码

## 方式二：Cloudflare Pages 手动部署

如果你想自己走一遍流程，或者暂时没搭 cfmanager——

### 1. Fork 仓库

去 Solara 的 GitHub 仓库，顺手点个 Star，然后 Fork。

### 2. 创建 Pages 项目

Cloudflare 控制台 → **Workers 和 Pages** → **创建** → **Pages** → **连接到 Git**，选刚 Fork 的仓库。

构建设置全部留空就行——不需要构建，根目录即站点，无框架预设。点 **保存并部署**。

### 3. 可选配置

| 配置项 | 在哪设 | 说明 |
|--------|--------|------|
| 访问密码 | Pages → Functions → 环境变量，键 `PASSWORD` | 不设就免密，谁都能访问 |
| 界面语言 | 同上，键 `LANGUAGE` | 默认中文，`en` 切英文 |
| 数据持久化 | D1 数据库绑定，变量名 `DB` | 不绑的话数据存浏览器，清缓存就丢 |
| 自定义域名 | Pages → 自定义域 | 绑你自己的域名 |

D1 的建表语句在仓库 README 里，照拷就行。

### 想改点别的？

- **API 源**：改 `functions/proxy.ts` 里的 `API_BASE`
- **加功能**：项目本身是纯前端 + Cloudflare Functions，想改什么直接改代码就行，重新部署生效

## 它会花你多少钱

答案是——零。

| 资源 | 免费额度 | 日常够用吗 |
|------|---------|-----------|
| Pages 请求 | 10 万次/天 | 绝对够 |
| Pages Functions | 10 万次/天 | 搜索代理绰绰有余 |
| Workers | 10 万次/天 | API 中转不愁 |
| D1 数据库 | 5GB + 500 万次读/天 | 存歌单根本用不完 |

而且 Solara 做了智能边缘缓存，搜索结果别人搜过的你秒出，不走回源。所以实际消耗比上面这些数字还要低得多。免费额度对你来说就等于无限。

## 最后

总结一下：

- **有 cfmanager**：商店点一下，几十秒上线
- **没有**：Cloudflare Pages 手动部署，GitHub 账号就行

两个路子出来的是同一个东西——你自己的在线音乐播放器。不用买服务器，搜什么播什么。

跟大厂平台比，评论区、推荐算法这种生态层面的事肯定比不了。但 Solara 想的也不是去当平台——它就是把搜、听、下这三件事干到极致。

对我来说，一个干净的、不会弹窗的、歌单完全由自己掌控的播放器，已经很满足了。
