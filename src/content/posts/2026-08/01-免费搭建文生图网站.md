## 你不需要 GPU，也能跑文生图

说实话，之前每次看到别人用 Stable Diffusion 画图，我心里就痒痒。但一看配置要求——GPU、CUDA、显存 8G 起步……瞬间劝退。（别问我为什么不直接充 Midjourney，问就是喜欢折腾。）

后来发现一个路子：Cloudflare Workers AI。对，就是那个做 CDN 的 Cloudflare，他们居然也搞 AI 了，而且——**免费额度够用**。

开源项目 **text2img-cloudflare-workers** 把这一切打包好了，部署完就是一个完整的文生图网站。有 UI、有多模型、有密码保护、手机也能用。整个过程不需要写一行代码——而且，**完全免费**。不是"前 100 张免费"那种，是真的够你日常玩的免费。

![部署完成后的 txt2img 网站首页，展示提示词输入框、模型选择、生成按钮等完整 UI](https://i.ibb.co/nMCW1Rgm/text2img-web-ui-png.png)

下面我用两种方式带你把它跑起来——首选 cfmanager 一键部署，备选手动操作。

## 它能做什么

先看看效果，部署完之后你会得到一个这样的网页：

- 输入提示词，点生成，出图
- 支持 Flux、SDXL 等模型，随便切
- 能调尺寸、迭代步数、引导系数、随机种子（想折腾参数的话）
- 内置随机提示词，脑子空白时点一下就有灵感
- 可设访问密码，不设就是公开访问
- 深色/浅色模式，晚上用不刺眼
- 手机上也能正常用，响应式布局

## 前期准备

就一个东西：一个 **Cloudflare 账号**（没有的话去 cloudflare.com 注册，免费的）。

## 方式一：cf-manager 一键部署（强烈推荐）

cf-manager 是一个 Cloudflare 多账户管理平台，它自带一个**应用商店**，text2img 这个模板就在里面。（获取方式在文末。）

你不需要打开 GitHub、不需要在 Cloudflare 后台点来点去、不需要手动绑定 AI 资源。说白了就是填个名字，点两下，等几十秒，完事。

具体步骤：

打开 cfmanager → 左侧菜单进 **应用商店** → 搜 **Text2img Cloudflare Workers**（标签有 `worker`、`ai`、`文生图`）：

![cfmanager 应用商店，Text2img Cloudflare Workers 模板卡片](https://i.ibb.co/8DbKfpry/cfmanager-store-text2img-gif.gif)

1. 点 **确认部署**

![一键部署弹窗，填写 Worker 名称、确认部署](https://i.ibb.co/k6q0W5Zr/cfmanager-deploy-dialog-png.png)

2. 输入 Worker 名字，比如 `txt2img`
3. AI 绑定是自动创建的，不用你管
4. 确认，等部署跑完

然后打开生成的链接，搞定。

![cfmanager 一键部署成功，弹出部署地址](https://i.ibb.co/BKsR4XzV/cfmanager-deploy-success-png.png)

一键部署帮你跳过这些坑：
- 不用翻 GitHub 找仓库代码
- 不用在 Cloudflare 控制台手动建 Worker
- 不用去绑定设置的页面里找 Workers AI
- 模板始终拉最新版本，不会部署个过期的
- 万一半路出问题，自动回滚，不留垃圾资源

## 方式二：手动配置（备用）

如果你只是临时想部署这一个服务，不想搭 cfmanager，也不是不行。直接在 Cloudflare 控制台操作。

### 1. 创建 Worker

Cloudflare 控制台 → **Workers 和 Pages** → **创建应用程序** → **创建 Worker**，起个名，点部署。

![](https://i.ibb.co/3m6WDbTC/create-png.png)

### 2. 编辑并部署代码

点 **编辑代码**，清空默认内容。把 `src/worker.js` 全部代码贴进去，再新建 `index.html` 文件贴入 `src/index.html` 的内容，点 **保存并部署**。

![](https://i.ibb.co/5Wr6RmNW/edit-png.png)

### 3. 添加 Workers AI 绑定

进 Worker 设置 → **绑定** → **添加绑定**：
- 类型选 **Workers AI**
- 变量名填 **AI**
- 保存并部署

![](https://i.ibb.co/C3d3WxP9/ai-png.png)

### 4. 配置自定义域名（可选）

在 Worker 设置 → **域和路由** → **添加自定义域**，输入你的域名并完成 DNS 解析。

### 5. 想改点啥？（可选）

都在 `worker.js` 里面改，改完重新部署：

- **换模型**：搜 `AVAILABLE_MODELS`，增删模型 ID。模型 ID 去 [Cloudflare 文生图模型文档](https://developers.cloudflare.com/workers-ai/models/text-to-image/) 找
- **加密码**：搜 `PASSWORDS`，填 `["你的密码"]`，留空就是免密访问
- **换随机提示词**：搜 `RANDOM_PROMPTS`，换成你喜欢的梗
