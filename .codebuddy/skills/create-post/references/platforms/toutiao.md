# 今日头条（Toutiao / 头条号）发布与改写规则

**目标产物**：`generated/toutiao/<slug>.md`

## 1. 平台定位与调性
算法驱动的信息流平台，大众读者，偏好「信息增量明确、观点清晰、解决痛点」的干货资讯。

## 2. 审核红线
- **严厉打击向竞品导流**：严禁向微信公众号、微信群引流，命中直接扣信用分、掐断全网推荐流。
- **低质诱导互动（骗评）**：严禁文末写“评论区回复666领完整版”，会被算法识别为低质骗评并降权。
- **标题党与过度营销**：杜绝震惊体、虚假故事推广商品。

## 3. 改写与适配要点（高信息增量资讯）
- **标题设计**：标题突出信息增量与实用价值，不夸张、不标题党。
- **互动策略**：采用**模式 C（干货直出）**，正文直接交付所有价值，获取算法最大分发。
- **无外链与二维码**：删除所有站外链接与引流话术。

## 4. 专属 Checklist
- [ ] 第一行 `# 标题`，第二行 `> 摘要`，无 `---` YAML 头部。
- [ ] 标题与内容高信息增量，无低质诱导互动词。
- [ ] 零外链、零公众号二维码/引流尾巴。
- [ ] 文末附带 3~5 个 `#话题` 标签（如 `#科技 #编程 #效率工具`）。
