# CSDN 发布与改写规则

**目标产物**：`generated/csdn/<slug>.md`

## 1. 平台定位与调性
技术垂直社区，极度看重**技术干货、实操代码与踩坑经验**。纯「产品清单 / 羊毛汇总」极易被判定为软文。

## 2. 审核红线（命中必封/驳回）
- **恶意营销**：以引流为目的，附带 CSDN 未接入的第三方商业注册/下载链接。
- **软广「公司产品引流」**：非商务合作用户，文章虽有技术内容但最终在推销特定商业产品。
- **站外导流**：严禁出现公众号二维码、微信号、微信群以及文末「关注公众号领资料」等引流尾巴。

## 3. 改写与适配要点（技术教程形态）
- **文体转换**：将「产品清单/推荐」改写成「**技术教程 / 配置实战 / 踩坑记录**」，加入 `settings.json`、`.env` 配置片段与调用示例。
- **零裸外链**：删除所有“去 X.com 注册/下载”链接，改泛称“前往对应官网即可”。
- **产品当例子而非清单**：工具名可保留，但定位为“搭建过程中用到的工具”。
- **对冲与免责表述**：加入额度时效性、踩坑点、别绑死生产等客观中立表述。
- **互动策略**：优先采用**模式 C（干货全公开）**；若需站内互动采用**模式 B（评论区留言）**，严禁出现微信公众号字眼。

## 4. 专属 Checklist
- [ ] 第一行 `# 标题`，第二行 `> 摘要`，无 `---` YAML 头部。
- [ ] 零注册/下载裸外链，删除文末公众号引流尾巴。
- [ ] 包含实质性配置/代码/避坑内容。
- [ ] 文末附带 3~5 个 `#话题` 标签（如 `#开发者 #开源 #技术实战`）。
