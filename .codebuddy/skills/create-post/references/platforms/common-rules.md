# 跨平台多渠道分发通用规则与格式规范

本规范适用于所有外部平台分发子代理（Subagent）。在生成对应平台草稿前必须遵守以下底线原则：

---

## 1. 产物输出与头部格式规范

- **文件输出路径**：统一输出到 `generated/<platform>/<slug>.md`（如 `generated/csdn/<slug>.md`、`generated/xiaohongshu/<slug>.md` 等）。
- **自动创建父目录**：子代理在写入文件前，必须确保目标目录已递归创建（`mkdir -p` / `mkdir(..., { recursive: true })`），避免写入异常。
- **彻底剥离 YAML 元数据**：
  - ❌ **严禁包含** Astro / Firefly 的 `--- ... ---` YAML 代码块（剥离 `published/tags/category/slug` 等建站参数）；
  - ✅ **统一文件顶部结构**：
    - **第一行**：`# 标题`
    - **第二行**：`> 摘要/一句话简介`
    - **第三行起**：直接展开正文。
- **全平台文末话题标签**：所有平台 Markdown 文件文末均必须附带 **3~5 个精准的热门 `#话题` 标签**（如 `#技术分享 #AI工具 #开发日常 #开源`），方便各平台直接挂载标签或专栏。

---

## 2. 图片外链与图床机制（重要说明）

- **外链图片完全合规**：文章内包含的 Markdown 图片外链（如经 ImgBB 托管的 `https://i.ibb.co/...` 图床链接）**完全合规，严禁手动删除或替换**。
- **平台自动转存**：当文章复制粘贴到目标平台编辑器时，各平台会自动将外链图片拉取并转存到平台自建图床。
- **唯一图片检查项**：确认图片本身**无微信号/公众号二维码等引流水印**。

---

## 3. 引流与互动策略的三种模式

1. **模式 A：微信私域闭环（仅微信公众号适用）**：
   - 引导关注公众号并在后台回复关键词获取清单 + 作者签名，属于平台官方闭环功能，完全合规。
2. **模式 B：纯站内互动 / 评论留言（小红书 / CSDN 等社区运营）**：
   - 写法：`在评论区留言『免费AI』发你完整清单`（**绝对不能提公众号、微信等跨平台字眼**）。
   - 注意：私信频繁直发相同网盘链接易被风控。
3. **模式 C：全量干货公开（外部平台获取最大推荐流量的最佳实践）**：
   - 不设门槛，正文完整呈现配置与清单，文末泛化引导至各官网。知乎最易拿高赞、CSDN 易被推荐、小红书易成收藏爆款、头条/百家号算法推荐最大化。

---

## 4. 通用发布前自检清单（Checklist）

- [ ] **头部格式**：已剥离 `---` YAML，第一行 `# 标题`，第二行 `> 摘要`。
- [ ] **外链清理**：已移除所有外部注册/下载的裸链接与网盘裸链。
- [ ] **引流清理**：已彻底删除除目标平台允许范围外的引流尾巴与公众号字眼。
- [ ] **图片合规**：图片外链保留，图片本身无任何引流水印。
- [ ] **文末话题**：文末已附带 3~5 个 `#话题` 标签。
