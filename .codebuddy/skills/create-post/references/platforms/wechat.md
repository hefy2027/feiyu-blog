# 微信公众号（WeChat Official Account）发布与排版规则

**目标产物**：
- `generated/wechat/<slug>.html`（干净正文片段，供校验与归档）
- `generated/wechat/<slug>_预览.html`（带右上角一键「复制到公众号」按钮的交互预览页）

## 1. 平台定位与调性
私域粉丝沉淀平台，是**唯一允许建立自留地闭环互动**的合规阵地；允许适度建立作者个人品牌。

## 2. 审核红线
- **严禁诱导分享（红线）**：严禁写「转发朋友圈/微信群截图领资料」「分享解锁全文」等诱导行为（违者限制分享朋友圈或封号）。
- **过度营销与谣言**：严打低质软广与虚假夸大内容。

## 3. 外链机制与适配要点
- **正文外链受限**：个人/普通订阅号正文**无法添加外部超链接**（强行输入 URL 只显示为不可点击纯文本）。唯一合法外部超链接出口是文章底部的 **「阅读原文」**（可填外部已备案博客链接）。
- **互动钩子（模式 A）**：文末允许引导「关注公众号并在后台回复『XX』领取清单」（微信官方支持的标准能力）+ 附带固定作者签名：`我是 AI非与，一尾随性游弋的鱼。`。
- **排版引擎**：读取 `~/.agents/skills/gzh-design/SKILL.md` 技能执行 HTML 排版转换与合规校验，并按其规范调用 `wrap_preview.py` 生成一键复制预览页。
- **使用与粘贴指引**：
  - 直接用浏览器打开 `generated/wechat/<slug>_预览.html`；
  - 点击页面右上角自带的 **「复制到公众号」** 按钮（自动将带样式的富文本存入剪贴板）；
  - 在微信公众号后台编辑器中直接 `Ctrl+V`（或 `⌘+V`）粘贴即可。

## 4. 专属 Checklist
- [ ] 文末已按需包含后台关键词回复引导（模式 A）与作者签名。
- [ ] 严禁出现「转发朋友圈/微信群截图」等诱导分享违规词。
- [ ] 干净正文 `generated/wechat/<slug>.html` 与一键复制预览页 `generated/wechat/<slug>_预览.html` 均已生成并通过校验。
