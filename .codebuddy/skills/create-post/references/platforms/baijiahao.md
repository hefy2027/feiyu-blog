# 百家号（Baijiahao / 百度内容生态）发布与改写规则

**目标产物**：`generated/baijiahao/<slug>.md`

## 1. 平台定位与调性
百度搜索与信息流分发，SEO 权重高，偏资讯/干货/专业内容，适合吃百度搜索长尾流量。

## 2. 审核红线
- **图文一体审核**：直连百度商业版权库，严禁使用有版权瑕疵的第三方图片（配图必须为自有版权图或 AI 生成图）。
- **站外导流**：严禁留下任何微信号、电话、公众号等导流信息。
- **低质内容**：正文放裸外链或低质拼凑会被直接拦截，影响“百+”认证与推荐。

## 3. 改写与适配要点（搜索优化干货）
- **标题含关键词**：标题准确包含搜索关键词（利于百度收录），切忌纯标题党。
- **互动策略**：采用**模式 C（干货直出）**，正文结构完整，零站外引流。
- **外链泛化**：正文不出现下载注册裸链接，泛化为“前往官网”。

## 4. 专属 Checklist
- [ ] 第一行 `# 标题`（包含搜索关键词），第二行 `> 摘要`，无 `---` YAML 头部。
- [ ] 配图均为自有/AI生成，无版权水印。
- [ ] 零裸外链、零外部联系方式。
- [ ] 文末附带 3~5 个 `#话题` 标签（如 `#干货分享 #百度热搜 #科技数码`）。
