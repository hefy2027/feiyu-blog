# 知乎（Zhihu）发布与改写规则

**目标产物**：`generated/zhihu/<slug>.md`

## 1. 平台定位与调性
高知、专业、重逻辑与深度的问答社区。偏好「亲身体验 / 深度对比 / 实测踩坑」的长文与回答体。

## 2. 审核红线
- **严禁站外导流**：正文或文末放微信号、公众号二维码、加群引流会被系统折叠、删帖并扣除盐值。
- **诱导私信**：文末写“私信发你清单/资料”易被知乎反作弊系统判定为营销号折叠回答。
- **外链管控**：外链经 `link.zhihu.com` 中转，严禁商业推广、返利外链。

## 3. 改写与适配要点（深度回答/专栏体）
- **文体转换**：写成「**如何评价 / 如何高效使用 / 亲测方案与踩坑**」的回答体或知乎专栏长文。重论证逻辑与数据支撑。
- **互动策略**：必须采用**模式 C（全量干货完整交付）**，知乎读者与算法极度偏好在回答内直接交付完整干货。
- **零外链与零导流**：删除所有引流尾巴，商业工具泛称并引导至官网。

## 4. 专属 Checklist
- [ ] 第一行 `# 标题`，第二行 `> 摘要`，无 `---` YAML 头部。
- [ ] 采用模式 C 完整交付，无公众号引流尾巴，无诱导私信话术。
- [ ] 逻辑严密、论证充分、行文专业客观。
- [ ] 文末附带 3~5 个 `#话题` 标签（如 `#人工智能 #程序员 #软件开发`）。
