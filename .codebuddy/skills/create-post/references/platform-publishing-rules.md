# 跨平台发布规则与适配要点（百家号 / 小红书 / CSDN / 知乎 / 公众号 / 今日头条）

本文件供 AI 在把同一篇博客文章适配到不同平台时查阅。每个平台给出：**定位调性 → 审核红线（会拒/限流的行为）→ 适配要点（该怎么改写）→ 本文（free-AI 工具类）适配示例**。

> 通用铁律：凡涉及「把读者导到第三方站点 / 留联系方式 / 放外链 / 二维码」的行为，多数平台都视为营销引流；公众号是唯一允许合规引流自留地的平台。外链图床（如 ibb.co）在多数平台有风险，发布时优先用平台自带图床或自有版权图。

---

## 1. 百家号（百度 Baijiahao）

**定位调性**：百度搜索生态分发，SEO 权重高，偏资讯 / 干货 / 专业内容，适合吃搜索长尾流量。

**审核红线**
- 恶意营销、标题党、低质低俗、虚假谣言、封建迷信、侵权抄袭一律不行。
- **图文一体审核**：配图版权瑕疵直接拖垮整篇合规（未经授权用他人图 = 侵权）。
- 内容低质 / 图片质量差 → 发布不通过或被不推荐（不可投百+）。
- 反感到其他平台引流、过度营销 → 限流。
- 频次上限：图文 5 篇 / 天、动态 10 条 / 天。

**适配要点**
- 标题准确含关键词（利于百度收录），**切忌标题党**。
- 必须原创 + 配图自有版权（用 `archived-images/` 归档图或 AI 生成图）。
- 可保留「清单 / 干货」结构，但**不放大段裸外链**，外部站点泛称即可。
- 本文适配：写成「免费 AI 编码工具盘点（截至 2026-08）」型干货，注册下载链接泛化成「去对应官网」，强调时效与避坑，配图用自有。

## 2. 小红书（Xiaohongshu / RED）

**定位调性**：种草 / 真实分享社区，年轻向、重视觉与「真实体验」，像朋友安利而非教程。

**审核红线（社区公约 2.0，2026 持续收紧）**
- **引流红线极严**：个人资料禁含微信号、二维码、代购、水印、特定店铺等营销词；**笔记图片含二维码直接不通过**；正文禁出现「回购 / 购买 / 下单 / 价格 / 淘宝 / 天猫 / 京东」等购买引流敏感词。
- 过度营销识别：日更 > 3 条/天，或广告内容占比 > 40% → 限流（建议「3+1」：3 篇干货配 1 篇软）。
- 虚假营销、评论违规 → 限流 / 禁言 / 封号。
- AI 痕迹重、AI 托管账号、非原创搬运 → 限流。

**适配要点**
- **第一人称真实体验口吻**（「我试了 X」「踩坑了」），反对说明书腔。
- **零外链、零二维码、零价格/购买词、零水印**。
- 重封面图与排版美观；善用 emoji、短句、清单体（✅❌、序号）。
- 加话题标签 `#`。
- 本文适配：改成「我亲测还能白嫖的免费 AI 编码工具 🐟」个人体验笔记，去所有链接/价格，突出真实使用感受 + 避坑，配精美封面图，文末可带 `#AI工具 #免费 #编程`。

## 3. CSDN

**定位调性**：技术垂直社区，重技术干货与实质性内容；纯「产品清单 / 推荐」易被判定软文。

**审核红线**
- 恶意营销 = **以引流为目的 + 附带 CSDN 未接入的第三方链接 / 联系方式**（软广③「公司产品引流」、营销链接、硬广/二维码、图片水印带公众号）。
- 外链图床（如 ibb.co）属未接入第三方链接，有风险。

**适配要点（v4 已验证通过）**
- 改「产品清单」为「**技术教程 / 实战记录**」，加入配置片段、调用代码、踩坑等实质内容。
- **零裸外链**：删「到 X.com 下载/注册」链接，改泛称「去各自官网 / 搜一下就有」。
- 产品当例子而非清单；能泛化就泛化（如大厂 IDE 写「国内几个大厂出的编码 IDE」）。
- 加对冲表述（免费额度有时效、「免费」不全信、别绑死生产）。
- 删文末公众号引流尾巴。
- 发 CSDN 时图片重传 CSDN 图床、逐张检查无水印。
- 本文适配：即 `free-ai-ide-and-model-api-guide-v4.md` 形态（教程 + 配置 + 零外链）。

> CSDN 详细判定条款与通过 checklist 另见 `SKILL.md` 的「跨平台发布（CSDN 等）防广告-营销推广」小节。

## 4. 知乎（Zhihu）

**定位调性**：高知、专业、强信任社区，重逻辑、深度与客观，反对营销；适合回答体 / 长文。

**审核红线**
- 极反感导流到其他平台 / 留微信号；软文、硬广会被折叠 / 限流 / 删。
- 非原创、抄袭、洗稿。
- 标题党、虚假、煽动。
- 违规降「盐值」影响账号权重；商业推广须走知乎官方渠道（知+ 等）。

**适配要点**
- 用「回答 / 文章」形式，重逻辑、数据、亲身经历、客观分析，反对纯推荐罗列。
- 工具/产品可作为论证素材，而非主角；少罗列、多方法。
- **不出现微信号 / 外链引流**，可泛称。
- 本文适配：写成「如何零成本用上 AI 编码？附我的方案与踩坑」回答体，深度 + 经验，产品作例子，无导流。

## 5. 微信公众号（WeChat Official Account）

**定位调性**：私域粉丝沉淀，是**唯一允许合规引流自留地**的平台；允许适度自家营销。

**审核红线**
- 不得用 AI / 脚本 / 接口自动化替代真人创作（运营规范要求真人创作）。
- 政治、色情、谣言、侵权、虚假、诱导分享（「转发到群领 X」）、诱导关注为红线。
- 过度营销 / 垃圾广告 → 限流甚至封号；多次删文损耗账号权重。
- 原创声明须真原创。
- 合规范围内可使用自家二维码 / 阅读原文外链（指向自家站）。

**适配要点**
- 可保留较完整清单与引流（自留地）；允许「关注公众号回复 XX 领取」互动钩子 + 作者签名（详见 `SKILL.md` 第 12 步，且仅在确有可分发资源时加）。
- 避免标题党、谣言、侵权图。
- 本文适配：用 v1 / v3 完整清单版 + 文末「回复『免费AI』领取文中工具与模型清单」+ 作者签名「我是 AI非与，一尾随性游弋的鱼。」——这是公众号合规玩法。

## 6. 今日头条（Toutiao / 头条号）

**定位调性**：算法推荐、泛资讯、大众读者，重「信息增量」（专业知识、科学测评、亲身体验、理性观点）。

**审核红线**
- 过度营销：明显导流信息、二维码、外链、引流话术 → 限流 / 拦截。
- 故事诱导推广：虚构故事吸睛后推商品，且内容与推广不相关（内容电商规范）。
- 标题党（夸张 / 震惊 / 敏感词）、敏感词、非原创搬运洗稿、低质旧闻重复 → 限流。
- 反感把用户导到竞品平台。
- 合规推广走自带商品卡 / 微头条。

**适配要点**
- 标题突出「信息增量」、不夸张；正文重干货与亲身体验。
- **无外链 / 二维码 / 导流话术**。
- 可保留清单 / 干货结构，但避免硬广与引流。
- 本文适配：做「干货盘点」型，标题如「公司逼我用免费 AI，我整理了还能用的清单（附避坑）」，去链接，强调时效避坑，配图自有。
