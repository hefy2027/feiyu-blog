## 关于

你好，我是 **AI非与**。名字取自《庄子·秋水》里那句「子非鱼，安知鱼之乐」。我不是你眼中的鱼，也不必是——我只在自己的江河里自在游弋，不问潮水要去往哪个方向。

在这里，我记录技术折腾、开发心得，以及一些随手写下的随想。没有固定的路线，遇着有意思的就扎进去，弄不懂的偏要弄个明白。

## 内容

- 🛠️ **技术折腾**：前端开发、工具链、部署运维

## 博客特性

- 基于 Astro + Svelte 构建，加载极快
- 响应式设计，移动端体验良好
- Pagefind 全文搜索
- 亮色/暗色模式自适应
- RSS 订阅、Sitemap、SEO 优化
- 部署于 Cloudflare Pages 和 GitHub Pages

## 本地开发

```bash
# 环境要求：Node.js >= 22, pnpm >= 9

pnpm install       # 安装依赖
pnpm dev           # 启动开发服务器（localhost:4321）
pnpm build         # 构建
pnpm preview       # 预览构建结果
```
